=======================================
Hailo15 Camera Application Case Studies
=======================================

Overview
========
While the `Hailo-15 C++ Example Application <../ai_example_app/README.rst>`_ serves as a reference for building a more complex application on Hailo-15, the Hailo Camera Apps package also includes a set of case studies that demonstrate smaller, more focused examples of pipeline mechanics.

These case studies are designed to showcase specific mechanics for various scenarios, providing insights into how to leverage the hardware and software features on the Hailo-15 effectively.
They also serve as a simpler starting point for getting familiar with building application pipelines.

It is recommended to read the case studies in the follwoing order: 

- `Single Stream <single_stream/README.rst>`_: A simple single stream vision pipeline.
- `Detection <detection/README.rst>`_: A single stream detection application.
- `Dynamic Privacy Mask <dynamic_privacy_mask/README.rst>`_: An application for dynamic privacy masking of people.
- `Custom Stage <custom_stage/README.rst>`_: A custom stage that extends the Reference Camera API capabilites.
